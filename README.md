## 🧠 1. Overview

This is a simple and interactive **To-Do List Application** built using **HTML, CSS, Bootstrap, and Vanilla JavaScript**.  
The project helps users manage daily tasks in an organized way with a clean and responsive UI.

The main goal of this project was to practice **DOM manipulation, event handling, and JavaScript logic structuring**.

---

## ✨ 2. Features

- ➕ Add new tasks  
- ✏️ Edit existing tasks  
- 🗑️ Delete tasks  
- ✔️ Mark tasks as completed / not completed  
- 💾 Persistent storage using **Local Storage**  
- 🔄 Real-time UI updates without page refresh  

---

## 🛠️ 3. Tech Stack

- HTML5  
- CSS3  
- Bootstrap  
- Vanilla JavaScript  
- Local Storage API  

---

## 📚 4. What I Learned

During this project, I improved my understanding of:

- DOM Manipulation  
- Handling user input and events  
- CRUD operations (Create, Read, Update, Delete)  
- Working with Local Storage  
- Structuring JavaScript code in a cleaner and more maintainable way  

I also learned how important it is to separate logic from UI updates to keep the code scalable and easier to debug.
